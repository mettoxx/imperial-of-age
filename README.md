# Imperial of Age — Gizlilik sitesi

Türkçe, mobil uyumlu, derleme gerektirmeyen statik site.

## Yerelde çalıştırma

```sh
cd /workspace/imperial-of-age
python3 -m http.server 3000 --bind 0.0.0.0
```

`index.html` ve `styles.css` herhangi bir statik web sunucusunda yayımlanabilir. Harici yazı tipi, analiz veya izleme hizmeti içermez.

## Yayından önce

Metin yayın öncesi taslaktır. Geliştirici/şirket adı, gizlilik e-postası, gerçek veri kategorileri, amaçlar ve hukuki dayanaklar, hizmet sağlayıcıları ve politika bağlantıları, saklama süreleri, uluslararası aktarımlar, çocuklara ilişkin uygulamalar, başvuru/hesap silme süreçleri ve yürürlük tarihi doğrulanarak tamamlanmalıdır. Sonrasında taslak uyarıları ve doğrulama etiketleri güncellenmelidir.
